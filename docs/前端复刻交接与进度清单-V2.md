1. 拉起本地：`cd apps/web && npm run dev`（默认 3000 端口）。
2. 并排打开 `https://susu.da-ai.cc` 与 `http://localhost:3000`。

> 请把结果 `Out-File -Encoding utf8` 到文件，再用 Read 工具读取，或直接读 `.recon/` 下的产物。

## 4. 待办清单（按优先级）

### P0 — 全站视觉层（每个页面都受影响，优先级最高）

这些是 `docs/前端复刻差异清单-V1.md` 已记录、**尚未确认修复**的问题。建议第一个开新窗口就做这块，
因为它决定了「点进去页面和他不一样」的观感。

#### P0-1 `.ui-button` 基类与 Tailwind 工具类冲突 → 按钮全站变形

原站 `.ui-button` 只是基类，尺寸靠 Tailwind 工具类：

```
原站: ui-button ui-button-primary inline-flex items-center justify-center px-5 py-3 text-sm
      transition-all duration-200 disabled:pointer-events-none disabled:opacity-55
      rounded-xl border-0 bg-accent font-semibold tracking-wide text-on-accent shadow-glow
```

我们 `globals.css` 的 `.ui-button` 自己写了 `padding:.75rem 1.25rem; font-size:.875rem; border-radius:.75rem;`，
与 Tailwind v4 的 `rounded-xl` / `text-xs` 叠加：

| 属性 | 原站 | 我们 |
|---|---|---|
| borderRadius | 10px | 12px |
| fontSize | 12px | 14px |
| height | 40px | 43px |
| backgroundColor | rgb(39,39,39) | rgb(40,40,40) |
| gap | 4px 20px | 6px |
| transition | `0.2s cubic-bezier(.4,0,.2,1)` | `0.2s` |

根因：`@theme` 只声明到 `--radius-lg`，`rounded-xl` 实际取到 12px。

修法：
1. `@theme` 补齐原站 token：`--radius-sm:4px; --radius-md:6px; --radius-lg:8px; --radius-xl:10px; --radius-2xl:12px; --radius-3xl:16px; --radius-4xl:20px;`（原站实测值）
2. `.ui-button` 基类去掉 padding / font-size / border-radius，只保留 `display:inline-flex; align-items:center; justify-content:center; transition:...`
3. `--accent` 原站是 `#272727`（`rgb(39,39,39)`），我们是 `rgb(40,40,40)` → `--accent: 0 0% 15.29%`

#### P0-2 全局 `border-color: var(--border)` 无效 → 所有边框变成前景色

```css
* { border-color: var(--border); }   /* --border: 0 0% 0% / 0.06 */
```

`--border` 是含 alpha 的 HSL 片段，不能直接当颜色用 → 解析失败 → 回退 `currentColor`（前景色）。
实测：

```
body                        borderColor: orig=rgb(229,231,235)  ours=rgb(24,24,24)
.toolbox-selector-trigger   border:      orig=1px solid rgb(229,231,235)
                            ours=1px solid rgb(24,24,24)   <- 边框变黑
```

修法：改为 `border-color: hsl(var(--border))`，并拆分不透明 HSL + alpha 变量：

```
--border-h: 0 0% 90.2%;   /* #e5e7eb */
--border: 0 0% 90.2% / 0.06;
```

注意原站 `border-line` 实测是 `rgba(0,0,0,0.06)`，而 `border` 简写类默认是 `#e5e7eb`。

#### P0-3 `.prompt-composer-root` 高度塌陷（图片/视频页最显眼）

```
orig: height=662px  flexGrow=1  minHeight=0px
ours: height=220px  flexGrow=0  minHeight=auto
```

原站 class 尾部有 `min-h-0 flex-1 ... lg:flex-1 !bg-background`，我们缺 `flex-1`
→ 提示词编辑器不撑满，提交按钮被顶到页面中部。**这是「点进去页面不一样」的头号原因。**

#### P0-4 `.toolbox-selector-trigger` 边框色错

我们用 `text-fg` + `border`（走全局 `*` 规则 → 前景色），原站是 `text-foreground` + `border`。
配合 P0-2 修复即可，建议同时显式 `border-line`。

## 5. 关键实现备忘（避免下一位重复踩坑）

### 5.1 轮播（`BenchWorkspace.tsx` 的 `ExampleCarousel`）

```tsx
const count = images.length;
const [pos, setPos] = useState(1);
const [instant, setInstant] = useState(false);
const pendingReset = useRef<number | null>(null);

// count>1 时克隆首尾：[最后一张, ...全部, 第一张]
const slides = useMemo(
  () => (count > 1 ? [images[count - 1], ...images, images[0]] : images),
  [images, count]
);
```

- `go(+1)` 到 `count+1` → 记录 `pendingReset = 1`；`go(-1)` 到 `0` → 记录 `pendingReset = count`
- `handleTransitionEnd` 里：`setInstant(true)` + `setPos(target)` + 双 `requestAnimationFrame` → `setInstant(false)`
- 初始 `translate3d(-100%,0,0)`（指向第 1 张真实图）
- 活动索引归一化：`active = (((pos - 1) % count) + count) % count`
