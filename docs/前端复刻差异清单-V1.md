## 0. 总结

## P0 — 全站视觉层（每个页面都受影响）

### P0-1 `.ui-button` 基类与 Tailwind 工具类冲突 → 按钮全站变形
原站 `.ui-button` 只是**基类**，具体尺寸靠 Tailwind 工具类：
```
原站: ui-button ui-button-primary inline-flex items-center justify-center px-5 py-3 text-sm
      transition-all duration-200 disabled:pointer-events-none disabled:opacity-55
      rounded-xl border-0 bg-accent font-semibold tracking-wide text-on-accent shadow-glow
```
我们 `globals.css` 的 `.ui-button` 自己写了 `padding:.75rem 1.25rem; font-size:.875rem;
border-radius:.75rem;` → 与 Tailwind v4 的 `rounded-xl` / `text-xs` **叠加**，
实测差异：

| 属性 | 原站 | 我们 |
|---|---|---|
| borderRadius | 10px | 12px |
| fontSize | 12px | 14px |
| height | 40px | 43px |
| backgroundColor | rgb(39,39,39) | rgb(40,40,40) |
| gap | 4px 20px | 6px |
| transition | `0.2s cubic-bezier(.4,0,.2,1)` | `0.2s` |

**根因**：Tailwind v4 的 `rounded-xl` 定义在 `@theme` 里（`--radius-xl:10px`），
但我们 `@theme` 只声明到 `--radius-lg` + `:root{--radius-xl:10px}`，
`rounded-xl` 实际取到 **12px**（`--radius-2xl` 被 v4 重新映射）；
而 `.ui-button` 的硬编码 padding/font-size 又覆盖了工具类。

**修法**：
1. `@theme` 补齐原站 token：`--radius-xl:10px; --radius-2xl:12px; --radius-3xl:16px;
   --radius-4xl:20px; --radius-sm:4px; --radius-md:6px; --radius-lg:8px;`
   （原站 `.recon/static/98d0769010f05a67.css` 实测值）
2. `.ui-button` 基类**去掉** padding / font-size / border-radius，
   只保留 `display:inline-flex; align-items:center; justify-content:center; transition:...`
3. `--accent` 原站是 `#272727`（`rgb(39,39,39)`），我们是 `rgb(40,40,40)`
   → `--accent: 0 0% 15.29%`（39/255）

### P0-2 全局 `border-color: var(--border)` 无效 → 所有边框变成前景色
```css
* { border-color: var(--border); }   /* --border: 0 0% 0% / 0.06 */
```
`--border` 是**含 alpha 的 HSL 片段**，不能直接当颜色用 → `border-color` 解析失败
→ 回退 `currentColor`（= 前景色）。实测证据：
```
body           borderColor: orig=rgb(229,231,235)  ours=rgb(24,24,24)
.toolbox-selector-trigger border: orig=1px solid rgb(229,231,235)
                             ours=1px solid rgb(24,24,24)   ← 边框变成黑色！
```
**修法**：改为 `border-color: hsl(var(--border))`，并把 `--border` 拆成
不透明 HSL + alpha 变量：
```
--border-h: 0 0% 90.2%;   /* #e5e7eb */
--border: 0 0% 90.2% / 0.06;
```
注意原站 `border-line` 实测是 `rgba(0,0,0,0.06)`（不是 #e5e7eb），
而 `border` 简写类默认是 Tailwind v3 的 `#e5e7eb`。

### P0-3 `.prompt-composer-root` 高度塌陷（图片/视频页最显眼）
```
orig: height=662px  flexGrow=1  minHeight=0px
ours: height=220px  flexGrow=0  minHeight=auto
```
原站 class 尾部有 `min-h-0 flex-1 ... lg:flex-1 !bg-background`，
我们缺 `flex-1` → 提示词编辑器不撑满，提交按钮被顶到页面中部。
**这是"点进去页面和他不一样"的头号原因。**

### P0-4 `.toolbox-selector-trigger` 边框色错
我们用 `text-fg` + `border`（走全局 `*` 规则 → 前景色），
原站是 `text-foreground` + `border`（Tailwind v3 默认 `#e5e7eb`）。
配合 P0-2 修复即可，但需要显式 `border-line` 或保留 `border` 并修全局规则。
